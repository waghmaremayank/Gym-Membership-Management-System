# PulseFit Gym Management Dashboard

A responsive, browser-based gym management dashboard for members, trainers, plans, attendance, payments, workout schedules and management reports.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Dashboard overview with membership, revenue and attendance KPIs
- Member directory with search and quick-add member workflow
- Trainer and membership plan views
- Attendance and payment reporting views
- Workout schedule calendar
- Management insight cards for active memberships, attendance and payment follow-up
- Browser `localStorage` persistence for members added from the dashboard
